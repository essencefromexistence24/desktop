# DX Platform

AI assistant with ChatGPT-, v0- and Claude-like features, plus a shadcn/ui component registry.

## Stack

- **Web**: Next.js 16 (App Router)
- **Desktop/Mobile**: Tauri v2
- **Backend**: Drizzle ORM + Postgres
- **AI**: AI SDK v7
- **Monorepo**: Bun workspaces + Turborepo

## Getting started

```bash
bun install
bun run dev
```
